One fortune-cookie line, at most 140 characters, for an AI agent:

> Your future is bright, your context window is not, and this fortune just spent your very last token.

`main.py` writes that single line (100 characters, no trailing newline)
to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic, stdlib-only, no
network access. The line follows the fortune pattern: a concrete agent
condition (context window, tokens), a three-step escalation (bright
future, shrinking context, last token spent), and the punchline in the
last clause — the fortune itself spent the agent's very last token.
